# DropAgentX — Changelog 0.6.0 «سخت‌شده»

تاریخ: ۲۰۲۶-۰۸-۲۹ · ممیزی امنیتی کامل: ۹ باگ کریتیکال فیکس + آپشن جدید «فیلتر ضدکلاهبرداری»

## 🔴 فیکس‌های امنیتی/مالی
1. **Path Traversal آپلود** — اسم فایل تلگرام (کنترل‌شده توسط کاربر) مستقیم در مسیر
   ذخیره می‌شد؛ `../` می‌توانست خارج از uploads بنویسد یا فایل محصول قبلی را
   بازنویسی کند → پاک‌سازی + یکتاسازی با timestamp (`_safe_upload_name`)
2. **اسکرو غیراتمیک تسک** — چک موجودی و کسر دو مرحلهٔ جدا بود؛ دبل‌کلیک «ثبت نهایی»
   دو تسک با یک بودجه می‌ساخت (خلق پول) → hold اتمیک قبل از INSERT + برگشت خودکار خطا
3. **موجودی منفی** — `update_credits` کف نداشت؛ کسر بزرگ‌تر از موجودی موجودی را
   منفی می‌کرد → `MAX(0, credits + ?)`
4. **حافظهٔ ضدمتقلب معیوب** — `identity_rl` از `hash()` پایتون استفاده می‌کرد که
   هر ری‌استارت تصادفی است → حافظهٔ RL ذخیره‌شده در DB بعد از ری‌استارت آشغال
   می‌شد → هش پایدار blake2b
5. **قفل‌شدن جمعی پشت پرکسی** — rate limiter به `client.host` بود؛ پشت nginx همه
   127.0.0.1 → یک مهاجم کل سایت را 429 می‌کرد + لاگین ادمین قفل می‌شد → اعتماد
   به XFF فقط از IP پرایوت
6. **429 برای کاربر عادی** — سهمیهٔ 40/min شامل عکس‌های /media بود؛ یک صفحهٔ
   فروشگاه = کل سهمیه → استاتیک/مدیا از limiter معاف شد
7. **RCE مشروط سندباکس** — اجرای محلیِ کد AI با APP_ENV=local بدون ایزولاسیون
   (بدون شبکه/منبع) و با ارث‌بری کل env (توکن‌ها!) → فقط با `SANDBOX_ALLOW_LOCAL=1`
   + env سفید‌شده (توکن/کلید/رمز به فرزند نمی‌رسد)
8. **کوکی جعل‌پذیر** — بدون WEB_SECRET و BOT_TOKEN، امضا با رشتهٔ معروف dev
   می‌شد → حالا لاگین 503 می‌دهد (fail-closed)
9. **توکن ادمین ابدی** — تغییر WEB_PASSWORD نشست‌های قبلی را نمی‌مرد → امضای
   توکن ادمین مقید به رمز؛ عوض‌کردن رمز = اخراج همهٔ توکن‌های دزدی
   (توکن Mini App کاربران دست‌نخورده می‌ماند) · بونوس: سقف `limit` در APIها

## 🆕 آپشن جدید: 🛡️ فیلتر ضدکلاهبرداری
- عنوان/توضیح محصول قبل از انتشار بررسی می‌شود؛ ادعای «سود تضمینی»، بدافزار و...
  رد می‌شود (نرمال‌سازی ضد دورزدن: نیم‌فاصله، ك عربی، ارقام فارسی)
- فرمان ادمین: `/moderation on|off|add کلمه,کلمه|clear|status`
- پیش‌فرض روشن + لیست ۲۰ عبارتی — قابل افزودن از پنل

## ✅ QA
**۸۵/۸۵ تست** (+۱۳ تست رگرسیون برای همین فیکس‌ها و آپشن) · کامپایل کل ✓
