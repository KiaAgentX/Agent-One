# @dropagentx/webapp — Telegram Mini App (سطح B قانون ۹)

اپ تلگرام پروژهٔ واحد: **۳۰ صفحه**، دوزبانه (fa پیش‌فرض RTL + en)، موبایل‌فرست، Aurora UI —
هم‌خانوادهٔ داشبورد ادمین (React 19 + Vite 6 + Tailwind 4 + hash router بدون وابستگی).

## نقشهٔ صفحه‌ها
تنها منبع حقیقت: [`src/routes.ts`](src/routes.ts) — هر صفحه اعلام می‌کند منطقش از کدام ماژولِ
ادغام‌شده می‌آید (رد پای صفر-اتلاف برای ممیزی گام ۶). جدول کامل در `docs/RULEBOOK.md`، قانون ۹.

## وضعیت
- **گام ۲ (الان):** اسکلت — رجیستری ۳۰ صفحه + روت‌ر + i18n دوزبانه + wrapper تلگرام + StubPage.
- **گام ۵:** هر stub با UI واقعی خودش جایگزین می‌شود (بازار، کیف پول، اسکرو، اقتصاد ملت، ...).

## اجرا
```bash
pnpm install          # از ریشهٔ مخزن
pnpm --filter @dropagentx/webapp dev   # پورت ۵۱۷۴ — در مرورگر هم کار می‌کند
```

در تلگرام: منوی بات → دکمهٔ WebApp. پشت Fastify به‌صورت فایل استاتیک سرو می‌شود (قرارداد Phase-6).
